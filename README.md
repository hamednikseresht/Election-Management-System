# سامانه مدیریت انتخابات

نرم‌افزار شمارش تعرفه و نمایش نتایج برای مجمع عمومی. روی یک رایانه اجرا می‌شود: اپراتور آرا را ثبت می‌کند و همان داده روی نمایشگر سالن یا پروژکتور دیده می‌شود.

نیازی به اینترنت یا کلید API نیست. همهٔ داده در مرورگر همان رایانه ذخیره می‌شود.

## پیش‌نیاز

- [Node.js](https://nodejs.org/) نسخه **۱۸ یا بالاتر** (پیشنهاد: LTS فعلی)
- npm که همراه Node نصب می‌شود
- مرورگر کروم / اج / فایرفاکس به‌روز

بررسی نسخه:

```bash
node -v
npm -v
```

## نصب محلی

ابتدا مخزن را بگیرید (یا پوشه پروژه را باز کنید):

```bash
git clone https://github.com/hamednikseresht/Election-Management-System.git
cd Election-Management-System
git checkout development
```

اگر از قبل پوشه را دارید، فقط وارد همان پوشه شوید.

### ویندوز (Windows)

1. Node.js را از [nodejs.org](https://nodejs.org/) نصب کنید (گزینه LTS). هنگام نصب، تیک «Add to PATH» را فعال بگذارید.
2. **PowerShell** یا **Command Prompt** را باز کنید.
3. به پوشه پروژه بروید، مثلاً:

```powershell
cd "$env:USERPROFILE\Downloads\personal\Election Management System"
```

یا مسیر واقعی پروژه خودتان را بگذارید.

4. وابستگی‌ها و اجرای توسعه:

```powershell
npm install
npm run dev
```

5. در مرورگر باز کنید: [http://localhost:3000](http://localhost:3000)

توقف سرور: در همان پنجره ترمینال `Ctrl+C`.

اگر `npm` شناخته نشد، ترمینال را ببندید و دوباره باز کنید، یا نصب Node را تکرار کنید.

### لینوکس (Linux)

نصب Node با روش رسمی توزیع خودتان؛ مثال روی اوبونتو و دبیان:

```bash
sudo apt update
sudo apt install -y nodejs npm
node -v
```

یا با [nvm](https://github.com/nvm-sh/nvm):

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# ترمینال را دوباره باز کنید
nvm install --lts
```

سپس:

```bash
cd Election-Management-System   # یا مسیر پروژه
npm install
npm run dev
```

مرورگر: [http://localhost:3000](http://localhost:3000)

توقف: `Ctrl+C`.

## صفحات برنامه

| صفحه | آدرس | کاربرد |
| --- | --- | --- |
| پنل اپراتور | `/` | تنظیم انتخابات و ثبت آرا |
| پیش‌نمایش سالن | دکمه «پیش‌نمایش سالن» | دیدن خروجی قبل از پروژکتور |
| نمایشگر پروژکتور | `/?view=display` یا دکمه «مانیتور دوم» | تمام‌صفحه برای سالن |

در نمایشگر سالن، یک انتخابات حداکثر حدود نیمی از عرض صفحه را می‌گیرد؛ دو انتخابات همزمان هر کدام نصف عرض را دارند. فونت فارسی از پکیج محلی **Vazirmatn FD** بارگذاری می‌شود (بدون نیاز به اینترنت برای فونت).

## آموزش کار در روز مجمع

### ۱. ساختار برگزاری

در بالای پنل اپراتور مشخص کنید انتخابات **تکی** است یا **دو انتخابات همزمان** (مثلاً چند منتخب و بازرس).

### ۲. تنظیم انتخابات

برای هر انتخابات این موارد را وارد کنید:

- عنوان رسمی
- نوع شمارش: **چند کاندیدا (رقابتی)** یا **رأی اعتماد (آری / نه)**
- سقف تعرفه اگر تعداد برگه‌های توزیع‌شده مشخص است؛ در غیر این صورت «شمارش پویا»
- تعداد نفرات منتخب (فقط در حالت رقابتی)
- حد نصاب رقابتی: **اکثریت نسبی** (بیشترین رأی) یا **اکثریت مطلق** (بیش از نیمی از تعرفه‌های قرائت‌شده)
- نام کاندیداها و در صورت تمایل عکس

اگر سقف مشخص است، تعداد کل تعرفه‌های توزیع‌شده را بنویسید. درصد پیشرفت قرائت از همین عدد محاسبه می‌شود. در این حالت ثبت تعرفه فقط تا رسیدن به همان سقف ممکن است و **پایان رأی‌گیری** تا ثبت همهٔ برگه‌ها غیرفعال می‌ماند. اگر شمارش پویا باشد، سقفی برای ثبت وجود ندارد.

باطله و سفید را از جعبهٔ «ثبت برگه رأی» بزنید؛ شمارندهٔ جداگانه بالای نفرات منتخب برای انتخابات رقابتی وجود ندارد.

### ۳. ثبت تعرفه در حالت رقابتی

روی یک برگه حداکثر به تعداد **نفرات منتخب** می‌توان نام نوشت (کمتر یا مساوی). انتخاب بیشتر در پنل قفل می‌شود.

1. نام‌های همان برگه را انتخاب کنید (تا سقف نفرات منتخب).
2. «ثبت این برگه رأی» را بزنید. به هر نام انتخاب‌شده یک رأی و به تعداد تعرفه‌ها یک برگه اضافه می‌شود.
3. اگر برگه سفید یا مخدوش است «برگه باطله / سفید» را بزنید.
4. اگر اشتباه ثبت شد «بازگشت آخرین تعرفه» را بزنید.

درصد هر کاندیدا از **تعداد تعرفه‌های قرائت‌شده** است، نه از مجموع نام‌های نوشته‌شده.

میانبر صفحه کلید وقتی روی جعبهٔ ثبت تعرفه هستید (در دو انتخابات همزمان، همان جعبه‌ای که روی آن ایستاده‌اید):

| کلید | کار |
| --- | --- |
| `1` تا `9` | انتخاب یا لغو کاندیدای همان ردیف |
| `Enter` | ثبت برگه انتخاب‌شده |
| `/` یا `I` | ثبت باطله / سفید |
| `Backspace` یا `U` | بازگشت آخرین تعرفه |
| `Escape` | پاک کردن انتخاب‌های همین برگه |
| `F11` | تمام‌صفحه |

اگر دو یا چند نفر در مرز کرسی‌های منتخب هم‌رأی باشند، سامانه به‌جای انتخاب تصادفی وضعیت **تساوی کرسی** نشان می‌دهد تا هیئت رئیسه تصمیم بگیرد.

اگر **اکثریت مطلق** انتخاب شده باشد، منتخب فقط وقتی اعلام می‌شود که رأیش بیش از ۵۰٪ تعرفه‌های قرائت‌شده باشد. در غیر این صورت کرسی خالی می‌ماند.

### ۴. رأی اعتماد

حد نصاب، **اکثریت مطلق** از کل تعرفه‌ها است (بیش از ۵۰٪). نمایشگر و صورتجلسه هر دو از همین قاعده استفاده می‌کنند. فقط بیشتر بودن آری از نه کافی نیست.

### ۵. پایان رأی‌گیری

اگر سقف تعرفه مشخص است، دکمهٔ «پایان رأی‌گیری و صورتجلسه» فقط وقتی فعال می‌شود که همهٔ برگه‌ها ثبت شده باشند.

پس از پایان:

- شمارش قفل می‌شود و دیگر نمی‌توان رأی کم یا زیاد کرد
- صورتجلسه برای چاپ یا ذخیره JSON باز می‌شود

اگر لازم شد اصلاح کنید، «بازگشایی شمارش» را بزنید، تغییر دهید، دوباره پایان دهید.

### ۶. نمایشگر سالن

روی رایانه اپراتور «مانیتور دوم / پروژکتور» را بزنید و پنجره را به پروژکتور بکشید. دکمه همگام‌سازی روی تصویر سالن دیده نمی‌شود.

همگام‌سازی بین پنجره‌ها از طریق مرورگر همان رایانه انجام می‌شود. پیام‌ها فقط از همین برنامه پذیرفته می‌شوند.

### ۷. پشتیبان‌گیری

- آیکون دانلود: خروجی JSON از وضعیت فعلی
- آیکون آپلود: بازیابی فایل پشتیبان (قبل از جایگزینی تأیید می‌خواهد)

حذف یک کاندیدا از لیست، بدون تأیید «بله» انجام نمی‌شود تا کلیک اشتباه رأی‌ها را پاک نکند.

### ۸. قفل PIN اپراتور (اختیاری)

آیکون کلید در نوار بالا PIN چهار تا هشت رقمی می‌گذارد. بعد از تعیین PIN:

- پنل اپراتور تا وارد کردن PIN باز نمی‌شود
- نمایشگر پروژکتور (`/?view=display`) قفل ندارد
- همان زبانه تا بسته شدن مرورگر باز می‌ماند؛ زبانهٔ تازه PIN می‌خواهد
- آیکون قفل، پنل را فوری می‌بندد

PIN فقط جلوی دستکاری اتفاقی روی رایانهٔ اپراتور است، نه جایگزین پشتیبان‌گیری.

## ذخیره داده

داده اول در **IndexedDB** مرورگر ذخیره می‌شود و در صورت امکان یک نسخهٔ سبک در `localStorage` برای همگام‌سازی زبانه‌ها می‌ماند. اگر عکس‌ها فضای `localStorage` را پر کنند، شمارش در IndexedDB حفظ می‌شود.

پاک کردن کش مرورگر آرا را حذف می‌کند. قبل و بعد از مجمع حتماً فایل پشتیبان بگیرید.

شروع تازه خالی است و اسامی ساختگی نشان داده نمی‌شود. اگر قبلاً نسخهٔ قدیمی را اجرا کرده‌اید، دادهٔ ذخیره‌شدهٔ همان مرورگر باقی می‌ماند؛ برای شروع مجدد از «پاکسازی کامل این انتخابات» یا بازیابی یک فایل خالی استفاده کنید.
